# robotnik.exe — The Machine Curse (fan project)

Selainpohjainen toimintapeli, jossa pelaaja taistelee konekirottuja droneja vastaan kolmessa wavessa ja lopuksi bossia vastaan.

> Huom: Tämä on alkuperäisteoksesta inspiroitu faniprojekti, ei 1:1-kopio videosta.

## Käynnistys

```bash
python3 -m http.server 8000
```

Avaa selaimessa: `http://localhost:8000`

## Ohjaimet

- `WASD` / nuolinäppäimet = liike
- `Hiiri` = tähtää
- `Vasen klikki` = ammu
- `Shift` = nopeampi liike (kuluttaa energiaa)
- `E` = EMP-purkaus
- `R` = restart
